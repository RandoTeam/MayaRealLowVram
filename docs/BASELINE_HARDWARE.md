# Экспериментальный базовый стенд (Hardware Baseline)

Данный документ содержит полное описание аппаратной и программной конфигурации нашего экспериментального стенда, на базе которого разрабатывается и тестируется адаптация **MayaRealLowVram** для видеокарт с низким объемом видеопамяти (8 ГБ, 6 ГБ, 4 ГБ и 3 ГБ).

Наш тестовый ноутбук выступает в роли **отправной точки (Tier 3: 4 GB VRAM)**.

---

## 1. Общие характеристики системы

| Параметр | Значение | Примечание |
| :--- | :--- | :--- |
| **Устройство** | Ноутбук Acer Aspire A715-42G | x64-based PC |
| **Операционная система** | Microsoft Windows 10 Pro 64-bit | Версия 10.0.19045, сборка 19045 |
| **Архитектура платформы** | AMD Zen 2 (Lucienne) + NVIDIA Ampere | Гибридная графика (iGPU + dGPU) |

---

## 2. Графическая подсистема (GPU & VRAM)

| Параметр | Значение | Описание / Значение для проекта |
| :--- | :--- | :--- |
| **Дискретный GPU** | **NVIDIA GeForce RTX 3050 Laptop GPU** | Архитектура Ampere (GA107) |
| **Объем видеопамяти (VRAM)** | **4096 MiB (4.00 GB) GDDR6** | **Отправная точка для адаптации (Tier 3)** |
| **Шина подключения** | PCI Express (Bus ID: `0000:01:00.0`) | PCIe Gen3/Gen4 x8/x16 |
| **Compute Capability** | **8.6** | Полная поддержка FP16, BF16, Int8, Int4 тензорных ядер |
| **Лимит мощности (TGP)** | 60.00 Вт (Ceiling Limit) | Энергоэффективный мобильный профиль |
| **Текущее энергопотребление** | ~7.5 Вт (idle) | В режиме ожидания |
| **Частоты ядра / памяти** | GPU: до 2100 МГц, Память: до 6001 МГц | Стандартные частоты мобильного чипа |
| **Версия видеодрайвера** | **617.14** (WDDM 2.7) | Новейшая ветка драйвера NVIDIA |
| **Поддерживаемая версия CUDA** | **CUDA 13.4** (CUDA UMD Version) | Драйвер поддерживает рантаймы CUDA 12.x и 13.x |
| **Интегрированный GPU** | AMD Radeon Graphics | 7 вычислительных блоков (Zen 2 Vega), доступна общая память |

> **Критический фактор для 4 GB VRAM под Windows:**  
> Модель драйверов WDDM резервирует часть VRAM (300–600 МБ) под композитор рабочего стола (DWM) и приложения. В результате для инференса доступно примерно **3.2–3.5 ГБ чистой VRAM**. Это требует максимальной экономии VRAM (квантование KV Cache до 4 бит, размещение базовых слоев и самых частых экспертов в VRAM, сброс остальных экспертов в RAM).

## 7. Роли оборудования в стратегии MayaRealLowVram

```
+---------------------------------------------------------------------------------+
|                       MayaRealLowVram Память и Иерархия                         |
+---------------------------------------------------------------------------------+
|                                                                                 |
|  [Tier 1: GPU VRAM] (4 GB GDDR6, ~3.2 GB доступно)                              |
|  * Внимание & Dense слои (Q4_K / Maya-S24 стиль)                                |
|  * Q4_0 KV Cache (контекст 4K - 8K токенов)                                     |
|  * Буфер наиболее частых горячих экспертов (Hot Experts)                       |
|                               ^                                                 |
|                               | Быстрая перекачка через PCIe Gen3/Gen4          |
|                               v                                                 |
|  [Tier 2: System RAM] (32 GB DDR4-3200 Dual-Channel, ~21 GB свободно)           |
|  * Закрепленный пул средних экспертов (Pinned Warm Experts)                     |
|  * AVX2 CPU вычисления для фоновых операций                                    |
|                               ^                                                 |
|                               | Высокоскоростной NVMe стриминг                  |
|                               v                                                 |
|  [Tier 3: NVMe SSD] (WD PC SN530 PCIe Gen3 x4, 188 GB свободно)                 |
|  * Хранилище редких экспертов (Cold Experts)                                    |
|  * Стриминг при генерации длинных ответов без переполнения RAM/VRAM             |
+---------------------------------------------------------------------------------+
```
