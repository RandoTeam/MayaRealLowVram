## 🎯 О проекте MayaRealLowVram

**MayaRealLowVram** — это специализированная модификация и инженерный форк проекта **[Project Maya](https://github.com/mw00/project-maya)** (на базе движка Strata), направленный на запуск флагманской модели **GLM-5.3-Flash** (321B параметров, 18B активных экспертов на токен) на массовых пользовательских конфигурациях с жестко ограниченным объемом видеопамяти: **8 ГБ, 6 ГБ, 4 ГБ и даже 3 ГБ VRAM**.

В оригинале модели такого масштаба требуют серверных ускорителей (A100, H100) либо связок из нескольких RTX 4090/3090. Данный проект использует многоуровневую иерархию памяти (**VRAM → Pinned RAM → NVMe SSD**) с микросекундной маршрутизацией экспертов и новейшими алгоритмическими оптимизациями релиза **v1.1.10**.

## 🚀 Ключевые возможности и ускорения (на базе v1.1.10)

В актуальном релизе v1.1.10 скорость генерации и эффективность работы с памятью были кратно увеличены благодаря внедрению следующих механизмов:

1. **KV Cache Streaming (`--kv-streaming on`, `--kv-resident 20480`)**:
   - Латентный кэш внимания выносится в закрепленную оперативную память (Pinned RAM), а в драгоценной VRAM удерживается только скользящее окно активных токенов.
   - Это освобождает до 1.5–3.0 ГБ VRAM, позволяя разместить в видеопамяти значительно больше слоев и экспертов MoE.
2. **Аппаратный спекулятивный декодинг DFlash2 (`--draft dflash2`)**:
   - Легковесный драфтер (~697 МБ) параллельно генерирует до 7 токенов за раунд на тензорных ядрах (NVIDIA Ampere sm_80+, включая RTX 3050).
   - Прирост скорости декодинга составляет **+19% .. +44% FPS**.
3. **Интеллектуальный пропуск холодных экспертов (`STRATA_GLM_DISK_SKIP_W`, `STRATA_GLM_DISK_SKIP_FROM`)**:
   - Эксперты, которые не поместились в VRAM и RAM, при низком весе роутинга не считываются с диска, исключая задержки случайного чтения SSD (ускорение до 1.6x при сохранении высокого качества ответов).
4. **Оптимизированные AVX2 MoE-ядра для CPU (`STRATA_GLM_CPU_MT`, `STRATA_GLM_CPU_1T`)**:
   - Мульти-токенные и одно-токенные векторные ядра ggml с декодированием знаков в регистрах ускоряют вычисления на процессорах AMD Zen 2/3/4 и Intel Core на 25–35%.
5. **Многопоточное чтение NVMe (`STRATA_GLM_DISK_READERS`)**:
   - Параллельные очереди чтения SSD сокращают время холодного старта и обработки длинных промптов (до +50% на быстрых NVMe).
6. **Автоматическая калибровка оборудования (`--calibrate`)**:
   - Движок замеряет скорость шины PCIe и пропускную способность оперативной памяти конкретной машины и оптимально делит нагрузку между GPU и CPU.
7. **Low-VRAM Zero-Copy UVA Архитектура (`STRATA_GLM_LOW_VRAM=1` / автоопределение при $\le$ 6GB VRAM)**:
   - Плотные веса модели (5.24 ГБ) и веса драфтера выносятся в закрепленную оперативную память хоста (Pinned Host RAM) через `cudaHostAllocMapped | cudaHostAllocPortable`.
   - Графический процессор обращается к ним напрямую по шине PCIe через Unified Virtual Addressing (UVA) с нулевым оверхедом по VRAM.
   - Это высвобождает критические гигабайты видеопамяти, позволяя сохранить **полный контекст 32,768 токенов** даже на видеокартах с 4 ГБ VRAM (например, RTX 3050 Laptop).
   - Динамическая калибровка драйвера снижает служебный оверхед до 256 МБ, гарантируя работу пула экспертов (от 4 до 9 слотов/слой) без падений по Out-of-Memory.

## 🔬 Экспериментальный базовый стенд (Tier 3: 4 GB VRAM)

Для отработки, профилирования и тестирования проекта используется реальный ноутбук:
- **Устройство:** Ноутбук Acer Aspire A715-42G (x64)
- **Видеокарта (dGPU):** NVIDIA GeForce RTX 3050 Laptop GPU (4 GB GDDR6, GA107, sm_86, TGP 60W)
- **Операционная система:** Windows 10 Pro 64-bit (Build 19045, WDDM 2.7)
- **Центральный процессор:** AMD Ryzen 5 5500U (6 ядер / 12 потоков, до 4.04 ГГц, AVX2)
- **Оперативная память:** 32 GB DDR4-3200 (Dual-Channel, ~21 GB свободно в покое)
- **Файл подкачки (Pagefile):** 16.0 GB (общий виртуальный лимит ~47 GB)
- **Накопитель:** WD PC SN530 NVMe SSD 512 GB (PCIe Gen3 x4, чтение до 2400 МБ/с, >200 GB свободно)
- **Программный стек:** Python 3.12, MSVC Build Tools 2026 (v19.51), CMake 4.4, Git 2.54.

Подробная спецификация стенда приведена в документе **[`docs/BASELINE_HARDWARE.md`](docs/BASELINE_HARDWARE.md)**.

## 📊 Матрица адаптации по уровням VRAM

| Уровень | Объем VRAM | Рекомендуемый квант | Распределение экспертов | Ожидаемая скорость |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1** | **8 GB VRAM** (RTX 3070/4060) | **Maya-S24** / **Maya-S** | ~30% в VRAM, ~65% в RAM, редкие на SSD | ~12–18 tok/s |
| **Tier 2** | **6 GB VRAM** (RTX 3060/2060) | **Maya-S24** | ~20% в VRAM, ~70% в RAM, редкие на SSD | ~8–12 tok/s |
| **Tier 3** | **4 GB VRAM** (Базовый стенд) | **Maya-S24** + Q4 KV | ~12% в VRAM, ~75% в RAM, хвост на SSD | ~5–9 tok/s |
| **Tier 4** | **3 GB VRAM** (GTX 1060 3GB / MX) | **Maya-S24** + Disk Skip | Базовые слои в VRAM, 80% в RAM, пропуск редких | ~3–5 tok/s |

## 📥 Загрузка моделей

Для максимальной надежности и прозрачности в репозиторий включен автономный скрипт загрузки, полностью повторяющий структуру путей Project Maya (`C:\AI\Maya-data\models\<quant>`):

### Интерактивный запуск:
```bat
DOWNLOAD-MODEL.bat
```
В интерактивном меню доступны:
1. **Dry-Run (проверка):** проверяет доступность удаленных ссылок на Hugging Face, свободное место на диске и структуру папок без скачивания данных.
2. **Скачать Maya-S24 + DFlash2:** скачивает модель с Q4_K вниманием (~94.7 ГБ) + файлы Vision (~1.14 ГБ) + спекулятивный драфтер DFlash2 (~0.7 ГБ).
3. **Скачать Maya-S24 без драфтера:** только веса модели и Vision.
4. **Скачать базовую Maya-S-v2:** оригинальный квант IQ2_XXS.
5. **Проверка контрольных сумм:** сверяет SHA-256 хэши скачанных файлов.

### Запуск через командную строку:
```bash
# Проверка ссылок и готовности диска:
python download_model.py --model Maya-S24 --with-dflash --dry-run

# Скачивание модели Maya-S24 с докачкой и проверкой SHA-256:
python download_model.py --model Maya-S24 --with-dflash
```

## 🛠 Запуск и сборка

1. Убедитесь, что установлен компилятор C++ и CUDA Toolkit (CUDA 12.0+ / 12.8):
   ```bat
   python maya.py --check
   ```
2. Запустите компиляцию и инициализацию через:
   ```bat
   START-MAYA.bat
   ```
3. Откройте веб-интерфейс в браузере: `http://127.0.0.1:8080`.
